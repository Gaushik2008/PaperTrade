# PaperTrade

Paper-trading web app with ₹10,00,000 virtual capital and trainable trading agents (Momentum, Mean reversion, Random).

- Open `index.html` in a browser.
- Runs on a simulated feed by default. To use live data, run a proxy to https://github.com/0xramm/Indian-Stock-Market-API and set the `API` constant in `index.html`.
- Virtual money only; no real funds.
